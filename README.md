# Spatially explicit demographic resilience

This repo contains the code associated with my notes on spatially explicit demographic resilience.

## Reproducibility

All statistical analyses were conducted in R. To reproduce all results, run:

```r
source("code/master.R")
```

`master.R` will:

- load required packages,
- create the output folders if needed,
- run all experiments,
- and generate the figures and tables.
